# Boggo CLI

Boggo Cloudin (https://cloud.boggo.fi) komentorivityökalu. **Tulossa.**

Tämä versio varaa paketin nimen. Kun työkalu valmistuu, sillä voi kirjautua Boggo Cloudiin, yhdistää kansion projektiin, julkaista
sovelluksen, hakea ympäristömuuttujat ja seurata lokeja suoraan omalta koneelta.

```sh
npx boggo
```

Seuraa: https://cloud.boggo.fi
